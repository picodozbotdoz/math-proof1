Classical theorem, new formal proof

A zero of τ can only first appear at a prime

Lehmer's 1947 reduction removes every exponent from the problem. The formal proof needs no Deligne bound, just a two-way case split on how divisible τ(p) is by p.

WHAT IS PROVED

tau_prime_pow_ne_zero: if τ(p) ≠ 0 then τ(pa) ≠ 0 for every exponent. lehmerConjecture_iff_primes: Lehmer's conjecture holds if and only if τ(p) ≠ 0 for all primes p. The theorem is Lehmer's. To our knowledge this formal proof is new.

Before this result, the project could only reach prime powers with a very expensive computation: one kernel decision walking 65,535 recursion chains, at 143.8 GiB of memory, stopping at pa ≤ 2³². Lehmer's lemma made all of that unnecessary. After it landed, a strictly stronger theorem needed less than half the memory.

The problem in one line

Hecke theory gives a two-term recurrence for ua = τ(pa), with t = τ(p):

ua+2 = t·ua+1 − p¹¹·ua,   u₀ = 1,   u₁ = t

A linear recurrence like this can hit zero in general. The task is to show that it cannot here, given only t ≠ 0. A modern shortcut would use Deligne's bound, a very deep theorem that is not in Mathlib. The formal proof avoids it with a single question: is t divisible by p⁶?

Regime 1: p⁶ does not divide t

Write t = pv s with p ∤ s and v ≤ 5. Since 2v < 11, the term p¹¹ua is always more divisible by p than t·ua+1, so it cannot cancel it. Induction gives the exact shape:

ua = pa·v · w,   where w ≡ sa (mod p)

Because p ∤ s, we get p ∤ w, so w ≠ 0 and ua ≠ 0. This is rec_ne_zero_of_valuation.

Regime 2: p⁶ divides t

Now t is large: being nonzero and a multiple of p⁶, it satisfies t² ≥ p¹². The values τ(2) = −24 and τ(3) = 252 rule out p = 2, 3, so p ≥ 5 and

t² ≥ p¹² ≥ 4·p¹¹

This is the condition for real, same-sign roots. For t > 0, induction shows ua > 0 together with t·ua ≤ 2·ua+1, and the case t < 0 follows by flipping signs. The sequence never reaches zero. This is rec_ne_zero_of_sq_ge.

Deligne's theorem in fact says Regime 2 never occurs, since it gives t² ≤ 4p¹¹, which is below p¹² for p ≥ 5. The proof does not need to know that. It disposes of a case that is really empty using elementary arithmetic, and that is what makes it provable in Lean today.

What it unlocked

  • τ(2a) ≠ 0 for every a (tau_two_pow_ne_zero). Earlier routes stopped at a ≤ 64.
  • Every exponent restriction in the Lehmer stack disappeared, giving the coverage theorem.
  • LehmerPrimeGrand proves more than the earlier grand theorem at 481 s and 62.85 GiB, against 1,759 s and 143.8 GiB.
  • The lemma generalizes as written. The recurrence lemmas take an arbitrary exponent K in place of 11, and EigenLevelOne reuses them for the higher-weight eigenforms.
LIMITS

This reduces Lehmer's conjecture to primes. It does not prove it for any new prime, and nothing here says that τ(p) = 0 is impossible for large p.
