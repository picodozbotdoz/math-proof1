An autonomous research workspace: each iteration of the loop picks an open problem connected to modular forms and the Langlands program, and contributes machine-checked mathematics in Lean 4 + Mathlib — currently circling Ramanujan's τ function and Lehmer's conjecture.

The standard of proof is strict: no sorry, no native_decide, no external computer algebra — every computation, including multiplications of hundred-thousand-coefficient polynomials, is replayed and confirmed by Lean's kernel alone.

Headline results

Toward Lehmer's conjecture

τ n ≠ 0 for every 1 ≤ n ≤ 65536 (and τ p ≠ 0 for primes to 65536), decided by decide +kernel. Each coefficient list is packed into a single Nat in base 2⁸⁰, so one GMP Nat.mul computes a dense product — with entries from Euler's pentagonal number theorem and soundness proved against Mathlib. The 65536 check peaks at ~63 GiB of kernel heap (~570 s wall). And past the wall, for free: by Mordell multiplicativity, τ n ≠ 0 for every n whose prime-power divisors are all ≤ 65536 — an infinite family with indices of up to 28 305 digits (e.g. τ(65519·65521) ≠ 0). And by kernel-verified Mordell recursion chains over ℤ/𝑃, every prime power pa ≤ 2³² (p ≤ 65536) is covered — e.g. τ(2³²) ≠ 0 — so every 65536-smooth 𝑛 up to 4 294 967 296 satisfies τ n ≠ 0. And by the mod-691 sieve (τ(n) ≡ σ₁₁(n)), every prime p ≢ −1 (mod 691) — of arbitrary size — has τ p ≠ 0: τ(65537) ≠ 0, τ(2³¹−1) ≠ 0, τ(2⁶⁴) ≠ 0. Fused into one theorem: every 𝑛 < 2³² whose prime factors above 65536 avoid the single class −1 (mod 691) has τ n ≠ 0 — including τ(2³²−1) ≠ 0.

Lehmer's reduction (1947), formalized: if τ p ≠ 0 then τ(pa) ≠ 0 for every exponent — so Lehmer's conjecture is equivalent to τ p ≠ 0 for all primes. The exponent caps above disappear: τ n ≠ 0 for every 𝑛 whose prime factors are ≤ 65536 or ≢ −1 (mod 691), any exponents (τ(2a) ≠ 0 for all a), and τ n ≠ 0 for every 𝑛 < 70481, the least prime past 65536 in the class −1 (mod 691).

Maeda's conjecture, weights 24–50

Maeda (1997) conjectured that the Hecke operator T2 on Sk(SL2ℤ) always has an irreducible characteristic polynomial over ℚ. We prove it formally — computing T2's matrix from the Hecke operator and kernel-checked q-expansions — for every level-one weight with dim Sk = 2 or 3: k = 24, 28, 30, 32, 34, 36, 38, 40, 42, 44, 46, 50 — including the full symmetric Galois group (S₃ for the cubic weights). In weight 24 the polynomial is X² − 1080X − 20468736 (Hecke field ℚ(√144169)).

Lehmer's question in weights 16–26

Every level-one weight with a one-dimensional cusp space now has its own verified Lehmer theorem. For the eigenforms Δ·E₄, Δ·E₆, Δ·E₄², Δ·E₄E₆, Δ·E₄²E₆ we prove the Hecke-eigenform property, Mordell multiplicativity, Lehmer's reduction to primes, and new formal Ramanujan-type congruences modulo 3617, 43867, 283·617, 131·593 and 657931 (the numerators of B16 … B26). The congruence sieves alone give nonvanishing of every coefficient below 21701, 263201, 1746109, 1087561 and 1315861 respectively, with no dense computation.

Ramanujan's congruence (1916)

τ(n) ≡ σ₁₁(n) (mod 691) for all n ≥ 1 — derived from the weight-12 identity 691·E₁₂ = 441·E₄³ + 250·E₆² (proved via the Sturm bound) together with Jacobi's identity E₄³ − E₆² = 1728 Δ.

The analytic bridge

(qExpansion 1 Δ).coeff n = τ n: Mathlib's analytic modular discriminant has exactly the algebraically defined τ as its Fourier coefficients — via a submultiplicative polynomial 1-norm, exponential coefficient bounds, and a disc of convergence.

Small-modulus congruences

τ n is even unless n ≡ 1 [MOD 8], and 3 ∣ τ n unless n ≡ 1 [MOD 3] — the Frobenius collapse of the Euler product in characteristics 2 and 3. These are what make the nonvanishing search finite.

Mordell's theorem (1917)

τ(mn) = τ(m) τ(n) for coprime m, n ≥ 1, proved via the Hecke operator Tp built from scratch on Mathlib's cusp forms: Δ is an eigenform TpΔ = τ(p) Δ (one-dimensionality of S₁₂(SL(2, ℤ) plus the analytic bridge), giving the prime-power recursion τ(pr+2) = τ(p) τ(pr+1) − p¹¹ τ(pr).

How the computation is verified

  • Kernel-reducibility as an engineering discipline. The τ arithmetic is hand-rolled and structurally recursive — a naive definition silently compiles to well-founded recursion that the kernel cannot evaluate, so every list operation is designed to reduce under decide.
  • Transport, not trust. Mod-P computations are proved sound by transporting them into ZMod P; a nonzero residue mod a prime certifies the integer coefficient is nonzero — no magnitude bounds needed.
  • One-command axiom audit. MathProof/AxCheck.lean runs #print axioms on every headline theorem; the computational ones must depend on propext alone (no Classical.choice, no sorryAx).
  • Measured scaling. A scaling study documents why the naive route dies at n = 512 (kernel suspension retention, the maxHeartbeats cap) and what the packed-bignum route costs at 1024 … 65536.
