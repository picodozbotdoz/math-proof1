# Bridge blueprint — Dedekind–Frobenius cycle types (Galois Sₙ for n ≥ 6)

**Status: blueprint, long-term workstream (Task AA cycle 1, trajectory 2).**
This is the genuine mathematical gap named by `research/maeda-scaling-study.md`
§2e and Iteration 18's next-steps: the ad hoc resolvent game stops at S₅, and
the generic Galois tool — *Dedekind's theorem* — is not in Mathlib.  The data
side is already done: `blueprint/exploration/data/maeda_dim6_10.json` contains,
for all 30 dim-6–10 weights, the cycle-type primes that would immediately
certify `Gal = Sₙ` once this bridge exists (findings §4).

## 1. The target statements

**Dedekind (cycle-type form).**  `f : ℤ[X]` monic, `Gal = Gal(f.SplittingField/ℚ)`
acting on `rootSet` (≅ `Equiv.Perm (Fin n)` after choice of ordering),
`ℓ` prime with `f̄ = f mod ℓ` **squarefree** (⟺ `ℓ ∤ disc f`), and

```
f̄ = ḡ₁ ⋯ ḡ_r   (monic irreducible factors over ZMod ℓ, degrees d₁ … d_r)
```

then `Gal` contains an element whose permutation has cycle type
`(d₁, …, d_r)` — a "Frobenius at ℓ".

**Jordan (group-theoretic finish).**  A transitive subgroup of `Sₙ`
containing a p-cycle for a prime `p ≤ n − 3` contains `Aₙ`.  (Mathlib has
`alternatingGroup.isSimpleGroup` but not Jordan.)  Then, for our weights:
irreducible charpoly ⟹ transitive; census p-cycle (p ≤ n−3) ⟹ ⊇ Aₙ;
`disc` non-residue mod some ℓ (census) ⟹ odd element ⟹ **Gal = Sₙ**.

Variant worth stating first (cheaper, covers 27 of 30 weights by the
census): transitive + **transposition** + p-cycle (p prime, p ≤ n − 3 — or
even the classical transposition + (n−1)-cycle form) ⟹ Sₙ — for these the
group theory is elementary (no Jordan), so it can land before Jordan does.

## 3. Proof strategy for Dedekind (the standard route, packaged for Lean)

Let `K = f.SplittingField`, `p` a prime of `ℤ` (= ℓ) unramified in `K`
(`ℓ ∤ disc f`), `𝔭 | ℓ` in `K`.  Steps:

1. **Factor–root dictionary over the residue field.**  `f̄`'s factors ḡ_i of
   degree d_i correspond to the orbits of Frobenius `x ↦ x^ℓ` on the roots
   of f in the algebraic closure of `ZMod ℓ`.  (Finite-field theory: an
   irreducible degree-d factor ↔ a Frobenius orbit of d conjugate roots.)
2. **Hensel lift.**  `f`'s factorization over `ℤ_ℓ` (the ℓ-adic integers)
   refines f̄'s with the same degrees — Newton/Hensel, squarefree case.
   Entry: `Mathlib/RingTheory/Henselian.lean` (+ `Padic` material).
3. **Decomposition group at 𝔭.**  `D_𝔭 = {σ : σ𝔭 = 𝔭}` surjects onto
   `Gal((K mod 𝔭)/F_ℓ)`; unramified ⟹ the quotient is cyclic, generated by
   the Frobenius `x ↦ x^ℓ`.  Mathlib has nothing packaged for number fields
   here (`Ideal`/`RamifiedIdeal`/`Ideal.norm` exist; decomposition groups do
   not — this is the largest sub-project).
4. **Lift to a permutation.**  Any preimage σ ∈ D_𝔭 of the arithmetic
   Frobenius acts on the ℓ-adic roots with exactly f̄'s orbit structure
   (step 2 + 3), i.e. its cycle type as an element of `Gal ↪ Sₙ` (via
   `galActionHom_injective`) is `(d₁, …, d_r)`.

Lean effort: **L** (a small algebraic-number-theory library: decomposition
groups for a splitting field over ℚ, unramified ⇒ cyclic quotient, Hensel
root-lifting).  Each step is classical; the packaging decision (how much
`RingOfIntegers`/`Ideal` machinery vs. a self-contained ℓ-adic route inside
`Polynomial`-land) should be settled by a survey of what
`Mathlib/NumberTheory/` already provides for `K` a general number field
(`RingOfIntegers`, `Ideal.nm`, ramification) before committing.

## 4. Staged delivery plan (each stage independently useful)

1. **Group theory first (no number theory):** transposition/(n−1)-cycle
   criterion + Jordan as a *hypothesis-bundle* lemma — "G transitive,
   contains a cycle of type T₁ and T₂ ⟹ G ⊇ Aₙ / G = Sₙ" over
   `Equiv.Perm (Fin n)`.  Light, uses `galAction_isPretransitive`.  Lets the
   project state `Gal = Sₖ` theorems *modulo* `Frobenius-of-type-…` facts.
2. **The Frobenius fact as a hypothesis interface**: state
   `exists_perm_of_factorization_type : (squarefree f̄) → ∃ σ : Gal, cycleType σ = degrees`
   and *assume* it in instance proofs.  Landing this makes the Sₙ data
   (census JSON) formally usable while (3) is in flight.
3. **Dedekind itself** per §3 — the Mathlib-sized contribution; also
   upstreamable standalone (`Polynomial.Gal.exists_frobenius_of_mod_factorization`).
4. **Jordan** (group theory, `M`): the standard proof (primitive-action
   argument) on top of `alternatingGroup.isSimpleGroup`.

## 5. Why this trajectory matters (impact)

* Unlocks the **full** Maeda conjecture (not just irreducibility) for every
  dimension at once — the census already covers dims 6–10, and the same
  5-line-per-weight certificate pattern scales to dim 25 (the study's
  end state) with zero new resolvent identities.
* Fills a real Mathlib gap (Dedekind's theorem is arguably the most-used
  "obvious" missing piece of computational Galois theory in Mathlib;
  `Polynomial.Gal` has the action machinery but no reduction bridge).
* Replaces the per-degree resolvent arms race (sextic F₂₀ resolvent at S₅,
  then nothing) with one dimension-generic theorem.
