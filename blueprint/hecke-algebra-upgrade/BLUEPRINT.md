# Blueprint — the Maeda-statement upgrade: `Tₙ ∈ ℚ[T₂]`

**Status: blueprint (Task AA cycle 3).** From `research/maeda-scaling-study.md`
§4 step 5: the "cheap general lemma" that upgrades every existing
"T₂-charpoly irreducible" theorem (dims 2–5 committed; dims 6–10 planned) to
the *usual* statement of Maeda's conjecture — the Hecke algebra of a level-one
space where `T₂` has irreducible characteristic polynomial is generated by
`T₂` alone:

```
theorem hecke_algebra_eq_QT2 {k : ℤ} (hchar : Irreducible (charpoly (T₂ | S_k)))
    (m : ℕ) : ∃ q : ℚ[X], (T_m | S_k) = (Polynomial.aeval q) (T₂ | S_k)
```

Statement value: high (this is what Maeda's conjecture literally asserts about
the Hecke algebra; irreducibility is the certificate).  Effort: **M** — one
light module of pure algebra + one Hecke-combinatorics extension.

## 1. Proof architecture (all over `ℚ`; `V := CuspForm 𝒮ℒ k`, `n := dim V`)

1. **`minpoly ℚ T₂ = charpoly T₂`.**  `minpoly_dvd_charpoly`
   (`Mathlib/LinearAlgebra/Charpoly/Basic.lean:97`, the `Module.End` version —
   the project's per-dim files already use `T.charpoly`, so the End charpoly
   is in play) gives `charpoly = minpoly · F`; irreducibility of `charpoly`
   plus `minpoly` non-unit (`V ≠ 0`: `aeval 1 T = 1 ≠ 0` never annihilates)
   plus both monic (`monic_minpoly`, `charpoly_monic`) forces equality.
2. **The field `ℚ[X]/(f)`.**  `AdjoinRoot.instField [Fact (Irreducible f)]`
   (`Mathlib/RingTheory/AdjoinRoot.lean:616`); `finrank ℚ (AdjoinRoot f) =
   f.natDegree = n` (`AdjoinRoot.powerBasis`/degree lemmas, same file).
3. **`V` as an `AdjoinRoot f`-vector space.**  `V` is a `ℚ[X]`-module via
   `X • v = T₂ v` (`Module.AEval'`, `Mathlib/Algebra/Polynomial/Module/AEval.lean:194`;
   `AEval'.of : V ≃ₗ[ℚ] AEval' T₂` even gives the ℚ-dimension bookkeeping).
   Since `f` annihilates `T₂` (Cayley–Hamilton, `aeval_self_charpoly` — End
   variant), the structure factors through `ℚ[X]/(f)`: the descent is the one
   piece that may need a small hand-rolled `Module (AdjoinRoot f) V` instance
   (via `AdjoinRoot.lift`-style smul, `AEval` does not ship it directly at
   this pin — **verify**; if absent, ~40 lines).
4. **Dimension count.**  `n = finrank ℚ V = finrank (AdjoinRoot f) V · n`
   ⟹ `finrank (AdjoinRoot f) V = 1` (tower formula; `Module.finrank`
   multiplicativity — verify exact name, e.g. `Module.finrank_mul_finrank`).
5. **`Tₙ` is `AdjoinRoot f`-linear.**  `Tₙ T₂ = T₂ Tₙ` (§2) ⟹ commutes with
   the whole `ℚ[X]`-action ⟹ with the quotient action.
6. **Finish.**  An endomorphism of a one-dimensional vector space over a
   field is multiplication by a scalar; preimage in `ℚ[X]` of the scalar
   under `ℚ[X] → AdjoinRoot f` gives `q` with `Tₙ = aeval q T₂`.  (Concretely:
   pick any `v₀ ≠ 0`, `Tₙ v₀ = c • v₀` with `c : AdjoinRoot f`, lift `c`.)

## 2. The Hecke side: `Tₙ T₂ = T₂ Tₙ` on level-one cusp forms

`HeckeLevelOne.lean` has `T_p` (prime `p`) with the coefficient formula
`(T_p f)_m = f_{pm} + p^{k−1} [p ∣ m] f_{m/p}`, proved via coset
factorization.  Two options:

* **(a) General `T_m` + double formula.**  Define `T_m` for all `m` (the same
  coset sum over matrices with determinant `m`), prove the two-variable
  coefficient formula `(T_m f)_r = Σ_{d ∣ gcd(m,r)} d^{k−1} f_{r m / d²}`…
  symmetric in the right way; commutativity + multiplicativity both fall out,
  and `T_m T₂ = T₂ Tₙ` follows by comparing coefficients + q-expansion
  injectivity.  This is the standard route and also upgrades `Mordell.lean`
  infrastructure to general `m` (useful later for the Lehmer axis).
* **(b) Minimal: only `Tₙ T₂ = T₂ Tₙ`.**  Factor `Tₙ` into `T_p`'s?  No —
  `T_p T_q = T_{pq}` holds for *coprime* p, q but prime powers repeat;
  the honest route needs `T_{p²}` etc. So (a) anyway.

Effort: the `T_m`-for-general-`m` extension is the bulk (coset
factorization for composite determinant — same proof shape as `T_p`,
parameterized); estimate 300–500 lines, light, no kernel decides.
