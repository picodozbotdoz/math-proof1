## 0. Objective / non-objectives

**Objective.**

* **(i) The generic ring theorem** `MathProof/ModularForms/HeckeRingGens.lean`
  (light; imports `HeckeTM`, `HeckeIndex`):
  `heckeRing_eq_adjoin_of_dim_le_ten`: for every level-one setup with
  `2 ≤ n = dim S_k ≤ 10` (same hypothesis shape as `heckeRing`), the Hecke
  ring equals the ℤ-subalgebra generated by `T₂, T₃, T₅, T₇`:
  `𝕋 = Algebra.adjoin ℤ {T₂, T₃, T₅, T₇}` (or `Subring.closure` — pick the
  formulation that transports; the CONTENT is the two inclusions):
  - `⊇`: each generator ∈ 𝕋 (`heckeTM_mem_lattice`) + 𝕋 subring;
  - `⊆`: `𝕋 = span_ℤ{T_1..T_n}`, `n ≤ 10`, and per multiplier the explicit
    reductions `T₄ = T₂² − 2^{k−1}T₁`, `T₆ = T₂T₃`, `T₈ = T₂T₄`,
    `T₉ = T₃² − 2^{k−1}T₁`, `T₁₀ = T₂T₅` (all instances of `heckeTM_mul`;
    odd primes 3,5,7 are generators; composites reduce) — **zero
    per-weight certificates** (F3).
  Instantiated at all 54 weights (a light generated file or a lean
  one-liner per existing weight namespace — no new data).
* **(ii) Per-weight refinements** (dims 5–10; needs b1's `HeckeLatticeIndex`
  API), in the measured **index form** (F4's route (b)):
  - `[𝕋 : ℤ[T₂,T₃]] = idx3` per weight: the subring-as-lattice
    `t23Lattice := span ℤ {T₂^a T₃^b : a + b < n}` (span-equals-ring via the
    integer charpoly power reductions — generic lemma), an explicit integer
    basis (HNF rows, emitted as literals) with `|det| = idx3` (`eval_det`),
    each basis row's membership via an entrywise matrix identity over the
    landed/probe-derived monomial coordinates (entries ≤ ~370 d — F4).
  - corollaries: `𝕋 = ℤ[T₂,T₃] ↔ idx3 = 1` per weight (true exactly at
    dims ≤ 4 — b2 territory, stated here for the 36 dims-5–10 weights as
    `≠`); **`𝕋 = ℤ[T₂,T₃,T₅]`** at the 22 `{3,5}`-weights (F2 list) via the
    same index form with `|det| = 1` (unimodular basis literal) — the
    certificate shape is (a)-or-(b) per F4: **G3 measures both** (does a
    plain n-subset of monomials have det ± 1? then (a) with zero
    coefficients; else HNF basis rows (b)); the >4 300-digit raw
    representation route is REFUTED (F4).
* **(iii) FINDINGS upgrade**: the greedy/minimality table (which sets
  suffice, where `{3}`/`{3,5}` fail) recorded as data + `≠` statements
  where they come free (idx3 > 1).  Full minimality (`{5}` never suffices
  etc.) is a NON-objective (needs index certificates for every subset).

**Non-objectives.**  SNF structure; D = I_k (b2); dims ≥ 11 (T₁₁ enters);
minimality beyond the idx3-refutation; Nicolas–Serre-style generalities.

## 5. Risks / fallbacks

* The `Algebra.adjoin ℤ` over a non-commutative `Module.End` — adjoin in a
  NONCOMMUTATIVE ring: Mathlib's `Algebra.adjoin` needs commutativity of
  the coefficient ring only; subring.closure is the safer phrasing — G2
  tries adjoin first, falls back to closure (`Subring.closure {T₂,T₃,T₅,T₇}`,
  the 𝕋-side uses `heckeRing` directly).
* Literal blow-up in (ii): the G3 decision gate is the protection; never
  push past it on momentum (descoping at a documented gate is success).
* b1 slippage: (i) is independent; (ii) waits or stubs per b2's pattern.
* Two workers editing `tools/gen_hecke_index.py` (b1 also extends it):
  coordinate via WORKLOG notes; prefer a separate `gen_hecke_ring_gens.py`
  importing shared helpers if conflict threatens (the default here).
