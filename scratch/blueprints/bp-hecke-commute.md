## 3. The mathematical core (small, but two traps)

For `f` a level-one cusp form of weight `k`, primes `p ≠ q`:

```
(T_p (T_q f))_m = (T_q f)_{pm} + p^{k−1} [p ∣ m] (T_q f)_{m/p}
                = f_{qpm} + q^{k−1} [q ∣ pm] f_{pm/q}
                  + p^{k−1} [p ∣ m] (f_{q m/p} + q^{k−1} [q ∣ m/p] f_{m/(pq)})
```

and the `p ↔ q` swap is equal after case-splitting the divisibility lattice
(`p ∣ m`, `q ∣ m`, `pq ∣ m`) — `omega`-friendly `Nat.Mod` case analysis;
`ring_nf`/`norm_num` finish each branch.  With injectivity of `qExpansion`,
`T_p (T_q f) = T_q (T_p f)` for all `f`, hence `Commute`.

Traps:
* **p = q**: `T_p² = T_{p²} + p^{k−1}` needs the multiplicativity beyond two
  DISTINCT primes; for the upgrade only `Commute (T_p) (T₂)` for arbitrary
  primes `p` (including 2) is needed.  `p = 2` against `T₂` itself is
  trivially commutative — restrict the statement to that shape first
  (`∀ p, Commute (heckeTP p) (heckeTP 2)`), keep full generality for later.
* **m/p not integral**: work the case splits on `m % p` / `m % q` with
  `Nat.Mod` lemmas BEFORE unfolding; the `[p ∣ m]` indicator is
  `if p ∣ m then _ else _` in `heckeTP_coeff` — restate per-branch with
  `Nat.dvd_iff` facts, mirroring how `Mordell.lean` consumes the same lemma.

Fallback if injectivity is awkward at the operator level: prove commutativity
on a spanning SET (the echelon bases of the 54 weights are literal in the
repo) — but the injectivity route is cleaner; grep first.

## 5. Risks

* **R1 injectivity**: the level-one q-expansion injectivity may need
  `k ≥ 1` side conditions or `Fact` packaging; if Mathlib's statement is for
  `ModularForm` (not `CuspForm`), lift through the coercion (cusp forms ARE
  modular forms; the coefficient function agrees).
* **R2 coefficient-formula composition**: `heckeTP_coeff` is stated for
  `(qExpansion 1 (T_p f)).coeff m`; composing twice requires re-indexing the
  expansion argument — should be a `rw` chain; if it fights, state and prove
  the composed lemma once (`heckeTP2_coeff`) and reuse it symmetrically.
* **R3 paywall**: none — no kernel decides at all beyond `norm_num`; the whole
  blueprint is elaborator-cheap.  If any proof is slow, split declarations
  (never raise options).
