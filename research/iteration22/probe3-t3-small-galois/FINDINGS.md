## 2. The n = 2…5 Galois routes

### 2.1 What `bijective_of_frobenius` needs (n ≥ 3 only — confirmed)

`MathProof/ModularForms/MaedaGaloisFull.lean:34-37`:
`bijective_of_frobenius (hq : q.Monic) (hn : q.natDegree = n) (h3 : 3 ≤ n) (hirr : Irreducible (ratOf q)) (hcyc : FrobHasCycleType (ratOf q) {n - 1}) (hswap : FrobHasCycleType (ratOf q) {2})`.
The `3 ≤ n` flows from the group-theoretic finish
`MaedaGalois.eq_top_of_isPretransitive_of_cycleType_of_isSwap_mem`
(`MathProof/ModularForms/JordanPrimitive.lean:225-235`, also `hn : 3 ≤ n`).
Certificates are turned into hypotheses by
`MaedaGaloisFull.cycleType_of_cert` (`MaedaGaloisFull.lean:112-128`): takes
`hcP : P = fromList c`, `P.Monic`, `(ratOf P).Separable`, `Fact ℓ.Prime`, a reflected
factorization `znorm ℓ c = znorm ℓ (mulLin ℓ rs g)` (`decide +kernel`), distinctness of `rs`
mod ℓ, `(toPoly ℓ g).Monic`, `Irreducible (toPoly ℓ g)` (Rabin, with Bézout witnesses via
`MaedaGaloisFull.irreducible_of_rabin_bezout`, :96-106), `(toPoly ℓ g).natDegree = d`,
and **`h2 : 2 ≤ d`** — and concludes `FrobHasCycleType (ratOf q) {d}`.
(Underneath: `FrobeniusCert.frob_cycleType_of_factorization`,
`MathProof/ModularForms/FrobeniusCycleType.lean:929-940`, also `h2 : 2 ≤ gb.natDegree`.)
`cycleType_of_cert` is degree-generic and is **reused unchanged** for every cofactor degree
`d ≥ 2`.

### 2.2 Per-n routes (recommendation: ONE uniform Frobenius route for n = 3, 4, 5; one tiny new lemma for n = 2)

* **n = 5** (weights 60, 64, 66, 68, 70, 74): `bijective_of_frobenius` directly.
  nm1 cert = `(X − r) × gbar`, `gbar` irreducible of degree 4; transp cert =
  `(X − r₁)(X − r₂)(X − r₃) × hbar`, `hbar` irreducible quadratic. No resolvent needed
  (contrast the T₂ dim-5 route `MaedaGalois5.lean`, which predates `MaedaGaloisFull` and
  pays the `Poly5` machinery — the Frobenius route is strictly cheaper).
* **n = 4** (48, 52, 54, 56, 58, 62): same, `gbar` degree 3 (contrast T₂'s
  `MaedaGalois4.lean` quartic-resolvent route). Both certs from factorizations.
* **n = 3** (36, 40, 42, 44, 46, 50): `h3 : 3 ≤ 3` holds, so `bijective_of_frobenius`
  works. **Both certificates have the same factorization shape `[2, 1]`**: `{n − 1} = {2}`
  and the transposition cert `{2}` are the same cycle type, so a single
  `(X − r) × (irreducible quadratic)` factorization literally certifies *both* hypotheses
  (the same Frobenius element is an (n−1)-cycle *and* a transposition). Two options:
  (a) emit two distinct-ℓ blocks and keep the generator skeleton byte-for-byte — the scan
  found distinct second primes for all 6 weights (see §3); (b) emit one block and pass it
  twice. Recommend (a): uniformity beats saving a trivial decide. *Wrinkle*: with `n := 3`
  the expected type of `hcyc` is `FrobHasCycleType _ {3 − 1}` while the cert produces
  `{2}`; `3 − 1` and `2` are defeq (literal `Nat.sub`, kernel/whnf-reducible), and if the
  elaborator ever complains, a 3-line wrapper `bijective_of_frobenius3` in the new infra
  module (apply with `h` twice) absorbs it. Low risk.
  (The alternative n=3 route — `MaedaGalois.galActionHom_bijective_of_cubic`,
  `MathProof/ModularForms/MaedaGalois.lean:30-72`, irreducible cubic + non-square
  `Cubic.discr` mod ℓ — is *not* recommended: `MaedaGalois.lean` is an ancestor of the heavy
  `MaedaGalois5Defs` chain (AGENTS.md gotcha), the Cubic-normalization `norm_num` is per
  weight, and the Frobenius route shares one generator skeleton with n = 4, 5.)
* **n = 2** (24, 28, 30, 32, 34, 38): `bijective_of_frobenius` is excluded by
  `h3 : 3 ≤ n`. **No factorization certificate is needed at all**: an irreducible quadratic
  over ℚ (char 0 ⇒ separable) has a transitive Galois action on its 2 complex roots, and the
  only transitive subgroup of S₂ is S₂. `maeda : Irreducible (P.map (Int.castRingHom ℚ))`
  is already exported by `MaedaT3SmallWeights`, so each n=2 weight costs one ~20-line
  Mathlib-glue proof, zero decides. Note this has *never been formalized even for T₂* —
  `MaedaWeight24.lean:28` says "For degree 2 the Galois group is automatically `S₂`" but no
  `galActionHom` statement exists for any dim-2 weight (T₂ Galois files start at dim 3).

  Mathlib-at-pin has **no** ready-made lemma: `Polynomial.Gal.galActionHom_bijective_of_prime_degree`
  (`Mathlib/Analysis/Complex/Polynomial/Basic.lean:128`) needs *two non-real roots*
  (`Fintype.card (p.rootSet ℂ) = Fintype.card (p.rootSet ℝ) + 2`) — dead end, Hecke
  eigenvalues are real (same reason `MaedaGalois.lean:14-16` rejected it). Greps for
  `galActionHom_bijective*` find only that lemma and its `'` variant. The proof sketch for a
  new lemma (name suggestion `bijective_of_quadratic`), all ingredients verified at the pin:

  ```
  -- in a NEW light module (imports Mathlib.Analysis.Complex.Polynomial.Basic +
  -- Mathlib.FieldTheory.PolynomialGaloisGroup), with
  -- attribute [local instance] Polynomial.Gal.splits_ℚ_ℂ   (Basic.lean:66)
  theorem bijective_of_quadratic {q : ℤ[X]} (hq : q.Monic) (hdeg : q.natDegree = 2)
      (hirr : Irreducible (ratOf q)) :
      Function.Bijective (Gal.galActionHom (ratOf q) ℂ)
  ```
  1. `Fintype.card ((ratOf q).rootSet ℂ) = 2` —
     `card_rootSet_eq_natDegree hirr.separable (IsAlgClosed.splits _)`
     (`Mathlib/FieldTheory/Separable.lean:441`), `natDegree_map`, `hdeg` (the pattern of
     `MaedaGaloisFull.lean:40-42`).
  2. `htrans : MulAction.IsPretransitive (Gal.galActionHom (ratOf q) ℂ).range (rootSet ℂ)`
     — from `Gal.galAction_isPretransitive`
     (`Mathlib/FieldTheory/PolynomialGaloisGroup.lean:181`) transported to the range
     exactly as `MaedaGaloisFull.lean:45-50` does (`MulAction.exists_smul_eq`,
     `Mathlib/Algebra/Group/Action/Pretransitive.lean:75`).
  3. `2 ≤ Nat.card range`: the orbit map `g ↦ g • a` from the range is surjective
     (`Fintype.card_le_of_surjective`, `Mathlib/Data/Fintype/Card.lean:270`), and the
     rootSet has 2 elements.
  4. `Nat.card range ≤ 2` (subgroup of `Equiv.Perm` of a 2-element type;
     `Nat.card_perm`), hence `range = ⊤` by
     `Subgroup.eq_top_of_card_eq` (`Mathlib/Algebra/Group/Subgroup/Finite.lean:118`),
     finish with `MonoidHom.range_eq_top` + `Gal.galActionHom_injective`
     (`Mathlib/FieldTheory/PolynomialGaloisGroup.lean:212`) — the same finish as
     `MaedaGaloisFull.lean:54`.
  Alternative (rejected) finish: `Equiv.Perm.subgroup_eq_top_of_swap_mem`
  (`Mathlib/GroupTheory/Perm/Cycle/Type.lean:546`, prime card + swap membership) needs a
  separate "nontrivial perm of a 2-element type is a swap" side-lemma — more work than the
  card count.

has no Maeda content; `GaloisProd.lean` there is unrelated — integer translates of periodic
functions). Conclusion: nothing to port, no conflicts; our transitivity-based n=2 lemma is
the right (and cheaper) route.

## 6. Blueprint shape (for the implementing blueprint author)

**Objective.** Complete Maeda's conjecture in full for the T₃ charpolys at every level-one
weight `k ≤ 134` with `2 ≤ dim S_k ≤ 10`: prove
`Function.Bijective (Gal.galActionHom (P.map (Int.castRingHom ℚ)) ℂ)` for all 24 small
weights (18 via two Frobenius certificates + `bijective_of_frobenius`; 6 via
`bijective_of_quadratic`), generated by `tools/gen_galoisfull.py --prime 3 --small` from a
freshly scanned, Lean-anchored certificate JSON.

**Non-objectives.** T₂ dim-2 Galois statements (never formalized; optional collateral —
same quadratic lemma would apply, but T₂ dim-2 charpolys live elsewhere and the census/scan
would be new work); dims ≥ 11; any Mathlib bump (stay on `v4.36.0-rc1` per
`research/mathlib-version-strategy.md`); touching the heavy `MaedaGalois5Defs` chain or any
pre-existing module except appending the root import; changing the registration policy of
`MaedaT3SmallWeights`; an umbrella weight-indexed theorem (per-weight statements match the
landed pattern).
